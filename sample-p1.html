20以内加减法

10课时5层难度95题

学习目标

  • 能熟练口算10以内的加减法
  • 掌握凑十法，正确计算20以内进位加法
  • 能用破十法和想加算减法计算20以内退位减法
  • 能计算整十数加减整十数

一、凑十法——20以内进位加法的核心

为什么这是P1最难的内容

从10以内加减到20以内，孩子面临第一次"进位"概念——个位满十要向十位进一。凑十法是攻克这个坎的最优策略：把计算转化为已经熟练掌握的10以内运算。

核心方法

看大数，分小数，凑成十，加剩数。例如 \(9+4\)：9差1到10 → 从4里拿出1给9 → \(9+1=10\)，4剩3 → \(10+3=13\)。

口诀：看大数，分小数，凑成十，加剩数。四个动作，一气呵成。

二、破十法——退位减法的利器

为什么难

\(13-5\)——个位3减5不够减，必须从十位"借1当10"。对孩子来说，这是第一次接触"退位"概念。

两种方法

破十法：十几拆成10+几 → \(10-5=5\)，\(5+3=8\)。
想加算减法：想 \(5+?=13\) → \(5+8=13\) → \(13-5=8\)。

● 例题详解 ●
L1 · 基础识记
\(9+4=（\ \ ）\)
  1. 看大数：9
  2. 想补数：9差几到10？差1
  3. 分小数：把4拆成1和3
  4. 凑十：\(9+1=10\)
  5. 加剩数：\(10+3=13\)
  6. 答案：13
L1 · 基础识记
\(15-7=（\ \ ）\)
方法一：破十法
  1. 拆：15 = 10 + 5
  2. 减：\(10-7=3\)
  3. 加：\(3+5=8\)
  4. 答案：8
方法二：想加算减法
  1. 想：\(7+?=15\)
  2. 口诀：七八十五
  3. 所以：\(15-7=8\)
  4. 答案：8
L3 · 多知识点结合
小明有8颗糖，小红比小明多5颗。两人一共有多少颗？
  1. 分析：先求小红的糖数，再求两人总数
  2. 小红：\(8+5=13\)（颗）—— 用凑十法
  3. 两人一共：\(8+13=21\)（颗）
  4. 答案：21颗
L5 · 探究拓展
用1-9各一次填入 □，使三个等式同时成立：
□+□=10，□+□=9，□-□=5
  1. 列举所有和为10的可能：1+9、2+8、3+7、4+6
  2. 尝试 3+7=10，剩余 {1,2,4,5,6,8,9}
  3. 从中找和为9的组合：1+8=9 ✓
  4. 剩余 {2,4,5,6,9}，找差为5的组合：9−4=5 ✓
  5. 验证无重复：{3,7,1,8,9,4}，各出现一次 ✓
  6. 答案：3+7=10，1+8=9，9−4=5

本章小结

  • 凑十法是20以内进位加法的核心策略——拆小数，补大数，凑十再加剩余
  • 破十法和想加算减法是退位减法的两种路径，选一种练熟即可
  • 所有20以内计算最终依赖10以内加减法的熟练度——基础不牢，后面全卡
  • 整十数加减（\(30+20\)、\(80-50\)）是两位数加减法的桥梁
