表内除法

8课时5层难度90题

学习目标

  • 理解除法的含义，知道除法是乘法的逆运算
  • 能用乘法口诀正确求商
  • 能区分"平均分"和"包含除"两种除法模型
  • 会用7-9的口诀求商

一、除法是乘法的"倒过来"

为什么除法是P2最难

孩子刚学会乘法（正向思维），马上要面对除法（逆向思维）。正向是"已知每份和份数求总数"，逆向是"已知总数求每份或份数"——思维方向的反转是最大的坎。

两种除法模型

等分除：\(12 \div 4 = 3\)——12个苹果平均分给4人，每人3个。
包含除：\(12 \div 3 = 4\)——12个苹果每3个装一袋，能装4袋。

同一个算式 \(12 \div 3 = 4\)，可以问"每人几个"也可以问"能分几份"——理解两种含义比算出答案更难。

二、用口诀求商——想乘算除

核心方法

做 \(56 \div 7 = ?\) 时，心里默念7的口诀：一七得七、二七十四……七八五十六——找到了！所以 \(56 \div 7 = 8\)。

关键技巧
  • 看除数 → 确定用几的口诀
  • 默念口诀 → 哪句的积等于被除数？
  • 另一个乘数就是商
● 例题详解 ●
L1 · 基础识记
\(20 \div 5 = （\ \ ）\)，用的口诀是？
  1. 看除数：除数是5，用5的口诀
  2. 默念：一五得五、二五一十、三五十五、四五二十
  3. 定位：四五二十的积正好等于被除数20
  4. 另一个乘数4就是商
  5. 答案：\(20 \div 5 = 4\)，口诀四五二十
L1 · 基础识记
\(72 \div 9 = （\ \ ）\)
  1. 看除数：除数是9，用9的口诀
  2. 默念：一九得九、二九十八……八九七十二
  3. 八九七十二的积等于被除数72
  4. 另一个乘数8就是商
  5. 答案：8
L3 · 多知识点结合
商店里有48支铅笔，每8支装一盒。卖掉3盒后还剩几支？
  1. 求总盒数：\(48 \div 8 = 6\)（盒）
  2. 求剩余盒数：\(6 - 3 = 3\)（盒）
  3. 求剩余铅笔数：\(3 \times 8 = 24\)（支）
  4. 答案：24支
L5 · 探究拓展
□ ÷ 7 = 8……3，求 □ 是多少。
  1. 回忆公式：被除数 = 商 × 除数 + 余数
  2. 代入：\(\Box = 8 \times 7 + 3\)
  3. 计算：\(8 \times 7 = 56\)，\(56 + 3 = 59\)
  4. 验证：\(59 \div 7 = 8\) 余 \(3\) ✓
  5. 答案：59

本章小结

  • 除法是乘法的逆运算——想乘算除是最自然的求商方式
  • 同一个算式有两种解释：等分除（平均分）和包含除（几个几）
  • 口诀熟练度 = 除法速度——乘法口诀越熟，除法越轻松
  • 0不能做除数——\(5 \div 0\) 没有意义
